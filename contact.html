자주 묻는 질문
데이터가 틀린 것 같아요 +
공식 홈페이지 링크와 함께 제보해주세요. 직접 원문을 확인 후 48시간 내에 수정하겠습니다. 오류 제보 시 어느 학교의 어떤 항목이 다른지, 그리고 공식 출처 URL을 함께 남겨주시면 가장 빠르게 처리됩니다.
정보가 언제 업데이트되나요? +
GitHub Actions를 통해 매주 월요일 오전 9시(KST)에 24개 학교 홈페이지를 자동 모니터링합니다. 페이지 변경이 감지되면 즉시 확인 후 업데이트됩니다.
AI가 생성한 이력서를 바로 제출해도 되나요? +
AI 생성 서류는 초안으로만 활용하세요. 실제 제출 전에 독일어 원어민 또는 독일 음대 경험자의 교정을 반드시 거치는 것을 권장합니다. 특히 Motivationsschreiben은 교수님 스타일에 맞게 개인화가 필요합니다.
입시 컨설팅도 받을 수 있나요? +
이메일로 문의해 주세요. 상황에 따라 개인 컨설팅이 가능합니다. 지원 학교 선택, 서류 검토, muvac 지원 과정 등에 대한 도움을 드립니다.
