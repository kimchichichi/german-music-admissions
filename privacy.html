"독일 음대 입시 판별기"는 한국 음대생 및 학부모를 위한 입시 정보 제공 서비스입니다. 이 방침은 본 서비스 이용 시 수집·처리되는 정보에 대해 투명하게 설명합니다.

01

수집하는 개인정보

본 서비스는 최소한의 정보만 수집합니다.

  • 자동 수집 정보 — 서비스 이용 시 브라우저 종류, 접속 IP 주소, 방문 페이지, 접속 시간 등이 자동으로 기록될 수 있습니다 (서버 로그).
  • 이메일 주소 — 대시보드 로그인 또는 문의하기 기능 이용 시 이메일 주소를 수집합니다.
  • 이용자 입력 데이터 — 이력서 생성기(CV Builder) 사용 시 입력된 이름, 학력, 경력 등의 정보는 서버에 저장되지 않으며 브라우저 내에서만 처리됩니다.
  • 쿠키 및 유사 기술 — Google AdSense, Google Analytics 등 제3자 서비스가 쿠키를 사용할 수 있습니다.
02

정보 수집 목적

  • 서비스 운영 및 유지 보수
  • 이용자 문의 응답
  • 서비스 개선을 위한 이용 통계 분석
  • 광고 게재 (Google AdSense)

수집된 정보는 위 목적 이외에 사용되지 않습니다.

03

제3자 서비스

본 서비스는 다음 제3자 서비스를 사용하며, 각 서비스는 독립적인 개인정보처리방침을 가집니다.

  • Google Analytics — 서비스 이용 통계 분석. Google 개인정보처리방침
  • Google AdSense — 광고 서비스 제공. Google 광고 정책
  • Supabase — 대시보드 로그인 및 데이터 저장. Supabase 개인정보처리방침
  • Anthropic Claude API — AI 서류 생성 기능. 입력된 정보는 API 처리 후 저장되지 않습니다.
  • GitHub — 소스 코드 및 데이터 호스팅.
04

광고 (Google AdSense)

본 서비스는 Google AdSense를 통해 광고를 게재합니다. Google은 맞춤 광고 제공을 위해 쿠키를 사용할 수 있습니다.

  • Google은 이전 방문 기록을 기반으로 맞춤형 광고를 표시할 수 있습니다.
  • 맞춤 광고를 원하지 않으시는 경우 Google 광고 설정에서 비활성화 할 수 있습니다.
  • 또는 www.aboutads.info를 통해 제3자 광고 쿠키를 거부할 수 있습니다.

광고 수익은 서비스의 무료 운영을 지원합니다.

05

쿠키 정책

쿠키는 이용자의 브라우저에 저장되는 소량의 텍스트 파일입니다. 본 서비스에서 사용되는 쿠키는 다음과 같습니다.

  • 필수 쿠키 — 서비스 기본 기능 제공에 필요합니다. 이를 거부하면 일부 기능이 작동하지 않을 수 있습니다.
  • 분석 쿠키 — Google Analytics가 방문 통계를 수집합니다.
  • 광고 쿠키 — Google AdSense가 관심 기반 광고 제공에 사용합니다.

브라우저 설정에서 쿠키를 비활성화할 수 있으나, 일부 서비스 기능이 제한될 수 있습니다.

06

데이터 보관 기간

  • 서버 로그 — 최대 90일 보관 후 자동 삭제.
  • 대시보드 이용자 데이터 — 계정 삭제 요청 시 즉시 삭제.
  • 문의 이메일 — 문의 해결 후 1년 이내 삭제.
  • CV Builder 입력 데이터 — 서버 전송 없음. 브라우저 세션 종료 시 삭제.
07

이용자의 권리

이용자는 다음 권리를 가집니다.

  • 본인에 관한 개인정보 열람 요청
  • 부정확한 개인정보 수정 요청
  • 개인정보 삭제 요청 (잊혀질 권리)
  • 개인정보 처리 제한 또는 이의 제기
  • 개인정보 이동성 요청

위 권리 행사를 원하시는 경우 아래 이메일로 연락주세요. 30일 이내에 처리됩니다.

08

외부 링크

본 서비스는 독일 음악대학 공식 홈페이지 등 외부 사이트로의 링크를 포함합니다. 외부 사이트의 개인정보 처리에 대해서는 본 방침이 적용되지 않으며, 각 사이트의 개인정보처리방침을 확인하시기 바랍니다.

09

어린이 개인정보

본 서비스는 만 14세 미만 어린이를 대상으로 하지 않습니다. 만 14세 미만 어린이의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 어린이의 개인정보가 수집된 사실을 인지한 경우, 즉시 삭제 조치합니다.

10

방침 변경 안내

본 개인정보처리방침은 법령 변경 또는 서비스 변경에 따라 업데이트될 수 있습니다. 중요한 변경이 있을 경우 서비스 내 공지 또는 이메일을 통해 사전에 알려드립니다.

현재 방침의 최종 업데이트일은 페이지 상단에 표시됩니다.
